Finanzas Final

Todos los prompts que he usadolos he pulido con chatgpt antes de pasarlo a gemini ya que no quería perder intentos o que hubiese errores en mis prompts y que hiciese mas lio en gemini.

Por lo tanto he hecho mi prompt con mis palabras, chatgpt lo ha traducido a un lenguaje mas exacto para gemini y asi he ido trabajando.


Es importante para esta aplicación tener que registrarse para poder acceder, porque cada cuenta tiene una serie de archivos, cada archivo de cada cuenta es privado. Entonces, si vas a probar la app, tendrás que registrarte, confirmar el e-mail que te han mandado, y luego iniciar sesión con ese e-mail.

const exchangeCurrency = useCallback((fromCurrency, toCurrency, amount, rate) => {
if (!balances[fromCurrency] || balances[fromCurrency] < amount) {
return { success: false, message: 'Saldo insuficiente' }
}


const newBalances = { ...balances }
newBalances[fromCurrency] -= amount
newBalances[toCurrency] = (newBalances[toCurrency] || 0) + (amount * rate)


setBalances(newBalances)

return { success: true, message: 'Conversión realizada' }
}, [balances])

PROMPT 10 — Sistema de suscripciones

Prompt: La app debe permitir gestionar suscripciones periódicas.

Prompt pulido

La app debe permitir gestionar suscripciones periódicas.

Código (SubscriptionsContext.jsx):

export function SubscriptionsProvider({ children }) {
const [subs, setSubs] = useState(() => {
const saved = localStorage.getItem('financepp_subscriptions')
return saved ? JSON.parse(saved) : []
})


const addSubscription = (name, cost, billingCycle) => {
const newSub = {
id: Date.now(),
name,
cost,
billingCycle,
active: true,
nextBilling: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000)
}
setSubs([...subs, newSub])
}


const monthlyCost = subs
.filter(s => s.active)
.reduce((sum, s) => sum + s.cost, 0)


return (
<SubscriptionsContext.Provider value={{ subs, addSubscription, monthlyCost }}>
{children}
</SubscriptionsContext.Provider>
)
}

import jsPDF from 'jspdf'
import 'jspdf-autotable'


export function exportToPDF(transactions, options) {
const doc = new jsPDF()


doc.setFontSize(20)
doc.text(options.title || 'Reporte Financiero', 14, 20)


doc.autoTable({
head: [['Fecha', 'Tipo', 'Concepto', 'Cantidad']],
body: transactions.map(tx => [
new Date(tx.date).toLocaleDateString(),
tx.type === 'send' ? 'Gasto' : 'Ingreso',
tx.contactName,
`${tx.amount}€`
]),
startY: 30
})


doc.save('finanzas.pdf')
}

export function exportToJSON(data) {
const jsonString = JSON.stringify(data, null, 2)
const blob = new Blob([jsonString], { type: 'application/json' })
const url = URL.createObjectURL(blob)


const link = document.createElement('a')
link.href = url
link.download = `finanzas_${Date.now()}.json`
link.click()


URL.revokeObjectURL(url)
}

npm run build

npx cap sync

npx cap open android

Build → Build Bundle(s) / APK(s) → Build APK(s)
Esperar compilación
APK generado en: android/app/build/outputs/apk/debug/app-debug.apk

Instalación:

# Instalar en dispositivo conectado
adb install app-debug.apk
